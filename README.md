# 📚 BestReads

Willkommen bei **BestReads** – deiner persönlichen Plattform für alles rund ums Lesen! 

BestReads ist eine moderne Webanwendung im Stil von GoodReads, die es dir ermöglicht, neue Bücher zu entdecken, deine Lieblingslektüren zu verwalten und deinen Lesefortschritt im Blick zu behalten. Ob du nach Empfehlungen suchst, deine Bibliothek organisieren möchtest oder einfach nur deine Gedanken zu einem Buch festhalten willst – BestReads ist dein treuer Begleiter auf deiner literarischen Reise.

## ✨ Features

- 📖 Bücher entdecken und durchsuchen
- 💾 Persönliche Bibliothek verwalten
- 📊 Lesefortschritt tracken
- ⭐ Bewertungen und Rezensionen schreiben
- 🎨 Moderne und benutzerfreundliche Oberfläche

## 🚀 Für Entwickler

### Schnellstart

Um die Webanwendung lokal zu starten, führe einfach folgende Befehle aus:

**Installiere alle Abhängigkeiten:**
```bash
npm install
```

**Starte den Development Server:**
```bash
npm run dev
```

Die Anwendung läuft dann auf `http://localhost:5173`

> **💡 Tipp:** Wenn du VS Code verwendest, kannst du die Befehle direkt im integrierten Terminal ausführen (Terminal → Neues Terminal) oder du klickst auf die ▶️ Play-Buttons, die VS Code bei code blocks anzeigt.

### Tech Stack

- ⚛️ React + TypeScript
- ⚡ Vite
- 🎨 Tailwind CSS
- 🧩 shadcn/ui Components
